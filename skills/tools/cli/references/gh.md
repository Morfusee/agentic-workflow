# GitHub CLI Reference

- Canonical executable: `gh`
- Version: `2.92.0` (2026-04-28)
- Last verified: 2026-08-08
- Help syntax: `gh <command> <subcommand> [flags]`; `gh <command> --help`; `gh help <topic>`
- Discovery: generated by `/cli create gh` using help-only recursive traversal on this host

## Environment and Authentication

- Requires GitHub authentication: `gh auth login`, then verify with `gh auth status`.
- Token-based auth: `GH_TOKEN` or `GITHUB_TOKEN` environment variables.
- Default host is `github.com`; other hosts require `--hostname` or `GH_HOST`.
- `gh repo set-default` binds a directory to a default repository.
- Actions, run, and workflow commands need repository context: `--repo [HOST/]OWNER/REPO`, current directory, or the default repository.

## Caveats

- `gh api` accepts arbitrary authenticated REST and GraphQL requests; treat it as an API client, not a typed command.
- Preview commands (`gh skill`, `gh agent-task`, `gh copilot`) may change behavior without notice.
- `gh alias` commands are user-defined. This host defines `co` (`pr checkout`), `mmdc`, and `morf` (both `auth switch` shortcuts for specific accounts); other hosts differ. Aliases are not part of the canonical command tree.
- Actions, run, and workflow commands need repository context.
- `gh auth token` prints a credential; never log it or commit it.
- Extensions installed via `gh extension install` add executable commands at runtime that are not listed here.
